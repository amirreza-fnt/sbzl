# صفحه «فهرست خدمات شهرداری سبزوار» — نسخه موبایل (فیگما، فریم 415:5)

## اجرا
فایل `index.html` را مستقیماً باز کنید (دوبار کلیک، بدون نیاز به سرور). صفحه هیچ درخواست شبکه‌ای ندارد و همه‌چیز (فونت‌ها، تصاویر، آیکن‌ها) داخل همین پوشه است.
عرض طراحی ۳۷۵ پیکسل و ارتفاع دقیق ۱۳۷۷ پیکسل است؛ در گوشی‌های دیگر (۳۲۰ تا ۴۸۰ پیکسل) به‌صورت تناسبی بزرگ/کوچک می‌شود و در دسکتاپ با عرض ۴۸۰ پیکسل وسط صفحه نمایش داده می‌شود.

## ساختار
- `index.html`، `css/app.css`، `js/app.js`
- `assets/`: لایه‌های تصویری با دو کیفیت (`@1x` و `@2x`)
- `fonts/`: فونت‌های پروژه (Peyda و PeydaWeb FaNum)
- `tools/`: ابزارهای ساخت و مقایسه (داده فیگما در `tools/src/`)

## بخش‌های تعاملی
- کاشی‌های خدمات: لینک واقعی، حالت هاور (بالا آمدن) و فشردن؛ کاشی «عوارض خودرو» با نشان «غیرفعال» غیرفعال است و پیام می‌دهد.
- بنر تبلیغاتی، دکمه‌های منو، اعلانات و پروفایل در سربرگ، دکمه‌های «مشاهده همه» و «سوالات متداول».
- اسلایدر «آخرین اقدامات شما»: راست‌به‌چپ، چرخشی و بی‌پایان، کشیدن با ماوس، سوایپ لمسی، کلیدهای ← و →، توقف روی کارت.
- بخش قفل‌شده (ورود به پنل کاربری) و نوار پایین ثابت با تب فعال و نشانگر متحرک (صفحه نخست و سوالات متداول صفحه را جابه‌جا می‌کنند).
- مقصدهایی که در این نسخه ایستا وجود ندارند، یک پیام کوتاه نمایش می‌دهند (بدون سرور).

## ساخت دوباره و مقایسه (اختیاری، برای توسعه‌دهنده)
نیاز به Python 3، Node.js، بسته‌های `playwright-core`، `pngjs`، `pixelmatch` و مرورگر Chrome دارد:
`./run.sh نام` ← ساخت کامل و مقایسه پیکسلی هر بخش با خروجی فیگما؛ `node tools/test.js` ← آزمون تعامل‌ها.
