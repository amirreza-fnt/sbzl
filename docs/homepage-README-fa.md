# صفحهٔ اصلی سبزوار (نسخهٔ تعاملی، منطبق بر فیگما)

## روش باز کردن
۱. فایل zip را در یک پوشه از حالت فشرده خارج کنید.
۲. ساده‌ترین راه: روی `index.html` دوبار کلیک کنید تا در مرورگر (Chrome / Edge / Firefox به‌روز) باز شود.
۳. (اختیاری) اگر خواستید با سرور محلی باز کنید:
   `python -m http.server 8000`
   و سپس آدرس `http://localhost:8000/index.html` را باز کنید.

## چه چیزهایی کار می‌کند
- اسلایدر اصلی و کارت کنار آن، کاروسل خدمات شهروندی، «فیلم‌های دیگر» و شهرداری‌ها: فلش‌ها، نقطه‌ها، کشیدن با موس و لمس، کلیدهای جهت‌نما، پخش خودکار (با توقف روی هاور/فوکوس)، چرخش بی‌پایان و جهت راست‌به‌چپ.
- فهرست اخبار کنار ویدیو اسکرول می‌شود (چرخ موس، لمس، کشیدن نوار اسکرول).
- حالت هاور کارت‌ها و دکمه‌ها، تب‌های اخبار و گزینه‌های شهر هوشمند، لینک‌ها و فرم خبرنامه.
- صفحه در هر عرضی کل پهنای پنجره را پر می‌کند (بدون فاصلهٔ خالی در کناره‌ها و بدون اسکرول افقی): طرح ۱۳۶۶ پیکسلی به‌صورت یکنواخت و متناسب با عرض پنجره بزرگ یا کوچک می‌شود؛ در عرض ۱۳۶۶ دقیقاً همان اندازهٔ فیگماست.

فایل‌های `js/slider.js` (کد اسلایدرها، بدون کتابخانهٔ خارجی) و `css/style.css` قابل ویرایش هستند؛ پوشهٔ `tools` فقط ابزارهای ساخت و مقایسه با فیگماست و برای اجرای صفحه لازم نیست.
